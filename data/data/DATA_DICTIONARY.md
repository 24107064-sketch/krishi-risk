# Data Dictionary: Krishi Risk Research Platform

This dictionary documents all tables, columns, statistical definitions, units, and sources generated by the pipeline.

---

## 1. Master Panel (`data/processed/master_panel.parquet`)
Key Identifier: `(censuscode, year)`
Unit of Analysis: District-Year (1990–2017)
Coverage: 296 major agricultural districts across 19 states (8,662 rows)

| Column Name | Type | Unit | Description | Source / Module |
| :--- | :--- | :--- | :--- | :--- |
| `censuscode` | int | - | Master Census 2011 nationwide district identifier (1 to 640) | Shapefile / Census 2011 |
| `DISTRICT` | string | - | Official District Name | Census 2011 |
| `ST_NM` | string | - | Official State Name | Census 2011 |
| `year` | int | Year | Calendar Year (1990 to 2017) | Longitudinal Key |
| `kharif_total_area_1000ha` | float | 1,000 ha | Total aggregated area under major Kharif crops (Rice, Sorghum, Bajra, Maize, Tur, Groundnut, Soyabean, Cotton) | ICRISAT DLD |
| `kharif_total_prod_1000t` | float | 1,000 tonnes | Total aggregated production under major Kharif crops | ICRISAT DLD |
| `kharif_composite_yield_kgha` | float | kg/ha | Weighted composite Kharif yield: $(\text{Prod} \times 1000) / \text{Area}$ | ICRISAT DLD |
| `yield_trend_kgha` | float | kg/ha | District-specific linear technology trend $\hat{Y}_{it} = \alpha_i + \beta_i \cdot t$ | Script 03 |
| `yield_residual_kgha` | float | kg/ha | Raw residual $e_{it} = Y_{it} - \hat{Y}_{it}$ | Script 03 |
| `yield_anomaly_z` | float | z-score | Normalized yield anomaly: $e_{it} / \sigma_i$ | Script 03 |
| `yield_deviation_pct` | float | % | Percent yield deviation relative to trend: $(e_{it} / \hat{Y}_{it}) \times 100$ | Script 03 |
| `shock_label_1sd` | int (binary) | {0, 1} | **Primary Target:** 1 if $z \le -1.0$ (yield residual falls $> 1$ SD below trend), else 0 | Module B Target |
| `shock_label_20pct` | int (binary) | {0, 1} | Secondary Target: 1 if yield falls $> 20\%$ below trend | Script 03 |
| `shock_label_severe` | int (binary) | {0, 1} | Severe Target: 1 if $z \le -1.28$ (~10th percentile cutoff) | Script 03 |
| `yield_kgha_lag1` | float | kg/ha | Yield in previous season ($t-1$) | Script 03 |
| `yield_anomaly_z_lag1` | float | z-score | Normalized yield anomaly in previous season ($t-1$) | Script 03 |
| `shock_label_1sd_lag1` | float | {0, 1} | Shock occurrence in previous season ($t-1$) | Script 03 |
| `rainfall_to_july_mm` | float | mm | Cumulative rainfall from June 1 to July 31 (Forecast Input) | IMD Pune (0.25°) |
| `rainfall_to_july_deviation_pct` | float | % | Percent anomaly of June-July rainfall relative to 1990–2010 normal | IMD Pune (0.25°) |
| `dry_days_to_july` | int | Days | Number of days with rainfall $< 1.0$ mm between June 1 and July 31 | IMD Pune (0.25°) |
| `longest_dry_spell_to_july` | int | Days | Maximum consecutive dry days ($< 1$ mm) between June 1 and July 31 | IMD Pune (0.25°) |
| `heavy_rain_days_to_july` | int | Days | Days with rainfall $\ge 64.5$ mm between June 1 and July 31 | IMD Pune (0.25°) |
| `tmax_to_july_mean` | float | °C | Mean daily maximum temperature between June 1 and July 31 | IMD Pune (1.0° regridded) |
| `tmin_to_july_mean` | float | °C | Mean daily minimum temperature between June 1 and July 31 | IMD Pune (1.0° regridded) |
| `tmax_to_july_anomaly` | float | °C | Deviation of July $T_{\max}$ relative to 1990–2010 baseline normal | IMD Pune |
| `hot_days_to_july` | int | Days | Number of days with $T_{\max} \ge 35$ °C between June 1 and July 31 | IMD Pune |
| `early_drought_flag` | int (binary) | {0, 1} | 1 if June-July rainfall anomaly $\le -20\%$, else 0 | IMD Pune |
| `monsoon_rainfall_mm` | float | mm | Total Kharif monsoon rainfall (June 1 to October 31) | IMD Pune (0.25°) |
| `monsoon_normal_mm` | float | mm | District climatological normal monsoon rainfall (1990–2010 mean) | IMD Pune |
| `rainfall_deviation_pct` | float | % | Full-season monsoon rainfall anomaly relative to normal | IMD Pune |
| `monsoon_rain_cv` | float | Ratio | Coefficient of variation of daily monsoon rainfall | IMD Pune |
| `monsoon_dry_days` | int | Days | Total dry days ($< 1$ mm) during June–October | IMD Pune |
| `longest_dry_spell_days` | int | Days | Maximum consecutive dry days during June–October | IMD Pune |
| `heavy_rain_days` | int | Days | Total heavy rainfall days ($\ge 64.5$ mm) during June–October | IMD Pune |
| `drought_flag` | int (binary) | {0, 1} | Full season meteorological drought (Deficit $\ge 20\%$) | IMD Pune |
| `irrigation_coverage_ratio` | float | [0, 1] | Net Irrigated Area / Net Cropped Area | ICRISAT DLD |
| `rainfed_area_share` | float | [0, 1] | 1.0 - Irrigation Coverage Ratio | ICRISAT DLD |
| `crop_diversification_index` | float | [0, 1] | Simpson's Index: $1 - \sum p_i^2$ based on crop area shares | ICRISAT DLD |
| `cropping_intensity` | float | % | Gross Cropped Area / Net Cropped Area $\times 100$ | ICRISAT DLD |
| `fertilizer_kg_per_ha_nca` | float | kg/ha | Total NPK consumption per hectare of Net Cropped Area | ICRISAT DLD |
| `vulnerability_index_equal` | float | [0, 1] | Module A IPCC Composite Vulnerability Score (Equal Weights) | Module A |
| `vulnerability_class` | category | {Low, Moderate, High} | Module A Tertile Vulnerability Classification | Module A |
| `exposure_subindex` | float | [0, 1] | Composite climate exposure dimension score | Module A |
| `sensitivity_subindex` | float | [0, 1] | Composite agricultural & demographic sensitivity dimension score | Module A |
| `lack_adaptive_capacity_subindex`| float | [0, 1] | Composite lack of adaptive capacity score ($1 - \text{Adaptive Capacity}$) | Module A |

## 2. Structural Vulnerability Index (`data/processed/vulnerability_index_districts.parquet`)
Key Identifier: `censuscode`
Unit of Analysis: District (Static long-term cross-section, 296 districts)

| Column Name | Type | Description |
| :--- | :--- | :--- |
| `exposure_subindex` | float | Mean of normalized rainfall CV, drought frequency, dry spell length, hot days, heavy rain days |
| `sensitivity_subindex` | float | Mean of normalized agricultural workforce %, agricultural labour %, rainfed area share, smallholder share, crop concentration, yield CV |
| `lack_adaptive_capacity_subindex` | float | Mean of inverted female literacy, overall literacy, irrigation coverage, fertilizer intensity |
| `vulnerability_index_equal` | float | Arithmetic mean of the 3 dimension sub-indices |
| `vulnerability_index_pca` | float | OECD PCA variance-weighted composite index score |
| `vulnerability_class` | category | Tertiles: Low (0–33%), Moderate (33–66%), High (66–100%) |
| `mpi_headcount_ratio` | float | External validation metric: NITI Aayog Multidimensional Poverty Index Headcount Ratio (%) |

## 3. Predictions Panel (`data/processed/predictions.parquet`)
Key Identifier: `(censuscode, year)`
Unit of Analysis: District-Year Out-of-Time Test Sample (2013–2017, 1,544 rows)

| Column Name | Type | Description |
| :--- | :--- | :--- |
| `shock_probability` | float | Isotonically calibrated harvest shock probability output by LightGBM model |
| `shock_prediction_binary`| int | Binary decision cutoff (1 if probability $\ge 0.25$, else 0) |
| `priority_score` | int (1 to 5) | Action Priority Score combining Module A Class and Module B Probability (5 = Critical, 1 = Low Risk) |
| `top_driver_1` | string | Highest contributing predictive risk driver from SHAP attribution |
| `shap_1` | float | Numerical SHAP value contribution of top driver |
| `action_1` | string | Rule-based suggested policy/contingency intervention |
| `top_driver_2`, `shap_2`, `action_2` | - | Second highest contributing risk driver and suggested action |
| `top_driver_3`, `shap_3`, `action_3` | - | Third highest contributing risk driver and suggested action |
